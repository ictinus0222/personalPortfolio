# CMS-Powered Minimalist Portfolio

This portfolio is designed like a CMS template, making it incredibly easy to update your content without touching any HTML.

## How to update your content

All your data is stored in a single file: `js/config.js`.

### 1. Edit `js/config.js`
Simply open `js/config.js` and update the values in the `portfolioData` object. You can add more projects, change your bio, or update your social links.

### 2. Assets
Place your images in the `assets/` folder and reference them in the `js/config.js` file (e.g., `assets/your-image.png`).

## Template Structure

- `index.html`: The structural shell of the portfolio.
- `css/index.css`: The styling and design system.
- `js/config.js`: **Your central content hub.**
- `js/main.js`: The engine that renders your content.

## Features
- **Responsive Timeline**: Experience and education formatted in a clean timeline.
- **Project Gallery**: Horizontal scrolling image galleries for project work.
- **Featured Writing**: High-profile placement for your best articles.
- **Contact Grid**: Unified links for all your social platforms.
